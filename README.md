# 档案元数据核对台

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的本地优先前端工作台，使用 Qwik、TypeScript 和 Qwik UI 构建。

## 功能

- 导入 A / B 两组记录，支持 JSON 数组、制表符和竖线分隔文本。
- 按标题、日期、人物、地点和编号加权匹配，显示综合分数与判断依据。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源，每个冲突字段可单独保留或拼接。
- 保存原始记录、字段来源选择、合并结果和忽略动作，形成完整审计轨迹。
- 支持撤销重做、离线 localStorage 保存和 JSON 核对包导出。
- 大量记录采用分批窗口渲染，匹配计算限制每条记录的候选数，避免一次挂载全部行。

## 目录快照对账

馆藏目录在核对台离线期间可能修订编号、权利或移除记录。对账功能按所有权分界同步：**目录管编号、权利和记录存活，本机管匹配结论、字段选择和审计轨迹**。

- **先提交后取快照**：同步先把上次版本后的本机变更（匹配结论、合并字段选择、对账裁决）从审计轨迹圈入发件箱逐条提交，再拉取目录新快照做三方对账（上次同步基准 / 本机当前值 / 目录新值）。
- **待裁项**：双方改了同一字段（编号或权利）时不覆盖任何一方，列出基准值、本机值、目录值供人工裁决；保留本机值会生成断言变更，下次同步提交目录。
- **留待处理**：目录移除而本机已合并的记录不自动清理，保留在待处理列表，由人工选择保留合并结果或接受目录移除。
- **中断与重试**：发送中断时已确认的进度和成功回执保留在发件箱；目录侧按变更 ID 幂等登记，重试同一批返回原回执、不重复写入。
- **导出对账记录**：导出每轮对账报告、待裁与裁决结果、留待处理项、成功回执和目录侧写入日志（JSON）。
- 界面提供“模拟目录离线修订”和“模拟发送中断”开关，用于演示和验证上述流程；目录服务由独立 localStorage 命名空间模拟（`src/utils/catalogService.ts`）。

```bash
npm run test:reconcile   # 对账引擎冒烟测试：提交 → 中断 → 重试去重 → 三方对账 → 裁决
```

## 技术栈

- Qwik 1.20
- TypeScript 5.9
- Qwik UI Headless `@qwik-ui/headless`
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

静态产物输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```

nginx 在容器内监听 `80`，宿主端口 `10020` 由根端口表或运行命令映射。

## 数据说明

记录和审计轨迹保存在当前浏览器。导入新记录后自动重新计算候选匹配，但不会自动确认或覆盖任何字段。
